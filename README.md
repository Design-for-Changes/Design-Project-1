# プロジェクト演習 Web表現リサーチ

調べた面白い・かっこいいサイトやWeb技術を、各自のAIを介して投稿する場所です。投稿されたデータを使い、教員側でマッシュアップを仕上げます。

## 自分のAIに渡すもの

1. [AI向け投稿マニュアル](FOR_AI.md)
2. 手元の調査資料。HTML、Markdown、Notionなど、今ある形式で構いません。

AIには、次のように依頼してください。

> FOR_AI.mdを全文読み、私の調査資料を投稿データにしてください。対応は日本語でお願いします。公開用ニックネームを確認し、サイトの見どころ、私のコメント、裏側の技術と根拠を整理してください。技術の推測やAIの補足は区別してください。公開前に内容を私に見せ、確認後にプルリクエストを提出してください。GitHubを操作できない場合は、投稿ファイルと提出方法を渡してください。

## 投稿する内容

- サイトや技術の名前とURL。
- 面白い・かっこいいと思った箇所と、自分のコメント。
- 具体的な動きや操作への反応。
- 裏側の技術と根拠。分からないものは未確認で構いません。
- データ表現への応用案や、AIが補った説明。

同じサイトを他の人が投稿していても構いません。別の見どころやコメントも、マッシュアップの材料になります。

## ニックネームと公開範囲

初回投稿時にAIが公開用ニックネームを聞き、投稿ファイルへ登録します。次回も同じ投稿者IDを使います。ニックネームは公開してよいものを選んでください。

このリポジトリは公開されています。GitHubの投稿アカウント等も見えるため、ニックネームだけで匿名になるわけではありません。学籍番号、連絡先、非公開資料などを含めないでください。

## 提出の流れ

AIが資料を読む → 不足するコメントなどを確認 → 投稿データを作る → 本人が公開内容を確認 → プルリクエストで提出。

データは `submissions/<投稿者ID>/<投稿ID>.json` に保存します。他の人の投稿は書き換えず、新しいファイルを追加します。提出後の取り込みと最終的な統合は教員側で行います。

マニュアルは編集ルールです。ブランチ保護などのGitHub設定を自動的に有効にするものではありません。
